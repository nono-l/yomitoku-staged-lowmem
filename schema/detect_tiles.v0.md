# detect_tiles/v0

既存の箱を避けた区画の目録である。検出器はまだ走らない。
分野語は持たない。

## 形

ルートはオブジェクト。

| 欄 | 型 | なぜあるか |
|---|---|---|
| schema | `"detect_tiles/v0"` | 箱の JSON と混ぜない |
| width / height | 整数 | 元画像の大きさ |
| tile | 整数 | 切った一辺 |
| min_ink | 数 | 余白を落とす閾値。0 なら画素を見ない |
| tiles | オブジェクトの配列 | 箱がほとんど無い矩形 |

tiles の各要素は `x y w h row col`。座標は元画像。
画像を渡したときだけ `ink` を付ける。絵も検出に渡す。インク比を上げて落とさない。

## やらないこと

- ここで検出器を載せない
- 伸長しない
- 既定の最短辺を変えない
- この版を run_staged.sh の既定に入れない
