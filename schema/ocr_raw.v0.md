# ocr_raw/v0

いまの `stage_recognize_onnx.py` が書く JSON の契約である。
分野語は持たない。読み順も持たない。検出順の配列である。
字が出たかは、この層で見る。組み立ては自信の低い行を隔離する。

## 形

ルートはオブジェクトの配列。

| 欄 | 型 | なぜあるか |
|---|---|---|
| content | 文字列 | 箱の中の活字。欠けることがある |
| rec_score | 数 0–1 | 認識の自信。低いと数字ごみが多い |
| det_score | 数 0–1 または null | 検出の自信。points.json 由来 |
| direction | 文字列 | 本体が返す向き。組み立てではまだ使わない |
| points | [ [x,y] × 4 ] | 四隅。読み順と切り出しの根拠 |

## やらないこと

- 店名・項目名をここで付けない
- 人物・場面・物体名をここで付けない
- 配列順を読み順とみなさない（検出順のまま）
- この版を黙って変えない。変えるなら版を上げる
