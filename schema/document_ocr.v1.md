# document_ocr/v1

`ocr_raw/v0` を、重み無しで読み順に戻した契約である。
分野語は持たない。

## 形

ルートはオブジェクト。

| 欄 | 型 | なぜあるか |
|---|---|---|
| schema | `"document_ocr/v1"` | 古い組み立てと混ぜない |
| source | 文字列または null | どの生 JSON から戻したか |
| text_in_order | 文字列の配列 | 上から、同じ段なら左から。本文側だけ |
| noise | オブジェクトの配列 | 低スコアや数字だけの断片。捨てず隔離する |
| words | オブジェクトの配列 | 本文側。v0 の欄に order を足す |

words の各要素は v0 の欄に加え `order`（0 始まりの読み順）を持つ。

## 隔離の境界

- rec_score が 0.25 未満
- 中身が2文字以下で、数字と記号だけ

境界を変えるなら版を上げる。店かどうかでは切らない。
